# Spike S1: extensions in Chrome style next to our own chrome

Pin: CEF 156.0.7 (Chromium 156), macOS arm64, spike target `SpikeChromeStyle` (`Spikes/ChromeStyle/main.mm`), built with
`scripts/build-app.sh --product SpikeChromeStyle --app-name "Spike Chrome Style"`. Evidence lives under `build/spikes/s1/`
(gitignored, local). Logs are the `[S1 <ms>]` lines the spike writes to stderr; screenshots are window-only captures.

Method notes that apply to every row:
- Every browser view uses `GetBrowserRuntimeStyle() = CEF_RUNTIME_STYLE_CHROME` and `GetChromeToolbarType() = CEF_CTT_NONE`,
  inside a frameless `CefWindow`.
- The spike is driven by a command file (CDP through `CefBrowserHost::SendDevToolsMessage`, plus synthesized `NSEvent`s posted
  into the spike's own windows). No system-level input injection was used.
- The test network resolves `pagead2.googlesyndication.com` to 0.0.0.0 (DNS-level ad blocking), so `adtest.html` reports
  `ad:blocked` with or without an extension. The runs therefore pass `--host-resolver-rules="MAP pagead2.googlesyndication.com 127.0.0.1:8443"`
  and `--ignore-certificate-errors` and serve a dummy `adsbygoogle.js` from a local TLS server. With that, a profile without the
  extension reports `ad:loaded` and only a profile with the extension reports `ad:blocked`.

Findings that bear on the M1 design:
- Extensions run in Chrome style with our own chrome around it: install, persistence across restart, `chrome.*` in extension pages and request blocking all work.
- One Chrome-style view per window is a hard rule; N tabs means N Chrome-style windows (works, heavier, slower to switch) or one Chrome view plus Alloy views.
- Native AppKit views must be siblings of the Views content view, not children, to receive mouse events.
- There is no CEF API for extension actions; toolbar UI for extensions has to be built from extension pages in a side window and by messaging the extension.
- Extension installation spawns a full Chrome browser window that the app has to hide or close.

S1 verdict: partial
